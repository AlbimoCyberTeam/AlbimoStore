# Albimo Store - Pro Marketplace Template

Template frontend & backend arsitektur headless modern menggunakan **Tailwind CSS**, terstruktur penuh untuk optimasi performa tinggi.

## 🚀 Langkah Instalasi Cepat
1. Salin seluruh skrip di atas ke berkas komputer Anda sesuai struktur folder yang diinginkan.
2. Pada file `firebase/config.js`, ubah konfigurasi string dengan akun Firebase Console milik Anda.
3. Pada file `assets/js/cloudinary-upload.js`, lengkapi kredensial cloud bucket Anda untuk fungsi upload gambar produk otomatis.
4. Jalankan berkas `index.html` menggunakan ekstensi **Live Server** di VS Code untuk langsung meninjau hasilnya.
